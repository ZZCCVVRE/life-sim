人生模拟器 · 重开一次
====================

一个单文件网页游戏。选三个天赋、分配属性、看一段随机人生，
遇到抉择时做选择，八条世界线、五十二种结局、二十六项成就。

文件说明
--------
index.html            游戏本体（纯自包含，无任何外部依赖）
manifest.webmanifest  应用清单（让手机可以"添加到主屏幕"）
sw.js                 离线缓存（断网也能玩）
icon-192.png          桌面图标
icon-512.png          桌面图标（高清）
icon-maskable.png     安卓自适应图标
apple-touch-icon.png  iPhone 桌面图标


方式一：手机直接打开（最简单）
------------------------------
把 index.html 发到手机（微信文件传输助手 / QQ / 邮件 / 数据线都行），
用浏览器打开即可玩。

注意：这种方式进度存在浏览器本地，换浏览器或清缓存会丢。


方式二：装成 App（推荐）
------------------------
需要把这个文件夹放到一个 https 网址上（或用电脑跑本地服务器）。

电脑上跑本地服务器（手机和电脑连同一个 Wi-Fi）：
  python -m http.server 8765 --directory .
然后在手机浏览器打开：
  http://电脑的局域网IP:8765/

打开后：
  iPhone —— Safari 底部"分享" → "添加到主屏幕"
  安卓   —— Chrome 右上角"⋮" → "添加到主屏幕"

装好后从桌面图标进入，全屏运行、没有地址栏，断网也能玩。

放到公网（可以永久保存链接，手机随时开）：
  - GitHub Pages：建仓库 → 上传这几个文件 → Settings → Pages → 选 main 分支
  - Netlify Drop：https://app.netlify.com/drop 直接把文件夹拖进去
  - Vercel：类似，选静态站点

注意：Service Worker（离线缓存）只在 https 或 localhost 下生效，
用局域网 http 地址访问时游戏能玩，但不会缓存离线。


进度说明
--------
历史回顾、成就图鉴、结局图鉴都存在浏览器 localStorage 里。
同一个浏览器、同一个网址下才会累积，换网址或清缓存会重置。


更新游戏
--------
替换 index.html 即可。如果手机上装过旧版，把 sw.js 里的
CACHE = 'life-sim-v1' 改成 'life-sim-v2'，系统才会拉新版本。
